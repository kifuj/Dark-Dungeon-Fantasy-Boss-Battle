Vous devrez présenter le projet jeudi après midi.
Vous devrez héberger votre projet (ex : vercel) => technos recommandées : stack JS + base de données Supabase (version gratuite)

## 1 - Construction du Product Backlog

Les étudiants doivent produire :

- User stories complètes (avec format “En tant que… Je veux… Afin de…”)

## 2 - Estimation (Planning Poker)

Chaque équipe estime toutes les stories avec Fibonacci. (Il s'agit de la suite de Fibonacci - 1, 1, 2, 3, 5, 8, 13, 21)

## 3 - Sprint 1 (0,5j) – Définition du Sprint Goal

Définir le sprint Goal
Faire le Sprint Backlog (et garder une trace avec un screen par exemple)
Exécuter le sprint
Simuler les daily scrum toutes les heures. Faire un compte rendu de chaque daily.

**15 minutes avant la fin** :

- simuler une sprint review (le PO présente le travail au reste de l'équipe) + garder une trace
- simuler une sprint retrospective (format `Keep / Drop / Try`)
